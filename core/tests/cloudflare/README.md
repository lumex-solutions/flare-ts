# cloudflare

Workerd-specific suites, run by the cloudflare project with this root's own `tsconfig.json`
(`@cloudflare/workers-types`). Tiers inside: `unit/`, `integration/in-process/`. The wrangler
fixture worker lives in `fixtures/`; Cloudflare test adapters in `helpers/`.

Rules: [standards/testing/structure.md](../../../standards/testing/structure.md)
